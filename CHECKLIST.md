### 4️⃣ ПРОВЕРИТЬ: Структура Firestore

Убедиться, что при создании чата в базе есть поле `participants`:

```
Firebase Console → Firestore Database
  → artifacts/{appId}/public/data/chats/{chatId}
  
Должны быть поля:
  ✓ participants: ["uid1", "uid2"] (как минимум 2 юзера)
  ✓ name: "Имя чата"
```

### 5️⃣ ТЕСТИРОВАТЬ НА ТЕЛЕФОНЕ (Android)

**1. Откройте приложение на мобильном браузере:**
```
Chrome → адрес вашего приложения
```

**2. Увидите баннер "🔔 Разрешите уведомления"**
- Нажмите "Разрешить"
- Браузер попросит разрешение → Разрешьте
- Появится сообщение "Push-уведомления включены! 🔔"

**3. Откройте консоль браузера (F12):**
- Filter: `FCM` или `Notif`
- Должны видеть логи инициализации Token

**4. Создайте чат с несколькими пользователями:**
- Вы = User A
- Второй телефон = User B

**5. Отправьте сообщение с User A → User B**
- На User B должно прийти уведомление, даже если браузер в фоне/закрыт!

## 🔍 ОТЛАДКА: Что смотреть

**Должны видеть логи типа:**
```

[FCM] Messaging инициализирован
[FCM] SW зарегистрирован: ServiceWorkerRegistration {...}

```

**Если видите ошибки:**
```
[FCM] Инициализация пропущена: ...
```
→ Скопируйте ошибку и проверьте VAPID ключ

### В Firebase Console → Logs:

**Ищите в логах Cloud Functions:**
```
[Push] Новое сообщение в чате {chatId}
[Push] Найдено {N} FCM токенов
[Push] ✅ Успешно отправлено: 1, ошибок: 0
```

**Если видите ошибку:**
```
[Push] FCM token отсутствует для {uid}
```
→ Может быть User еще не получил token (не нажал Разрешить)

## 📊 ДОПОЛНИТЕЛЬНАЯ ИНФОРМАЦИЯ

### Как работает сейчас:

```
1. User открывает приложение
   ↓
2. Показывается баннер (новая функция!)
   ↓
3. User нажимает "Разрешить"
   ↓
4. Браузер запрашивает разрешение ОС (новая функция!)
   ↓
5. Если разрешил - начинается инициализация FCM
   ↓
6. Firebase возвращает токен
   ↓
7. Токен сохраняется в Firestore (улучшено с логированием!)
   ↓
8. Когда приходит сообщение:
   - Cloud Function получает уведомление
   - Ищет участников чата
   - Для каждого ищет FCM token
   - Отправляет push через Firebase
   ↓
9. Service Worker получает push
   ↓
10. Показывает уведомление ОС
    ↓
11. User видит уведомление, даже если браузер закрыт
```

### Важные файлы:

- `index.html` - основная логика FCM
- `firebase-messaging-sw.js` - Service Worker (получает и показывает уведомления)
- `index.js` - Cloud Function (отправляет уведомления)
- `PUSH_NOTIFICATIONS_SETUP.md` - полная документация

## 🆘 ЕСЛИ НЕ РАБОТАЕТ:

### Симптом: "Баннер не показывается"
✓ Проверьте F12 → Console → фильтр `Notif`
✓ Убедитесь, что `Notification.permission` = `default` или `granted`

### Симптом: "Токен не сохраняется"
✓ Откройте F12 → Firestore Database
✓ Посмотрите users/{uid} → должна быть строка `fcmToken`
✓ Посмотрите логи в консоли - ищите `[FCM]` сообщения

### Симптом: "Уведомление не приходит"
✓ Убедитесь, что оба User имеют fcmToken в Firestore
✓ Посмотрите Firebase Console → Functions → Logs
✓ Ищите errors про "forbidden" или "invalid token"
✓ Проверьте, что VAPID ключ правильный

### Симптом: "На iOS не работает"
✓ К сожалению, iOS PWA имеют ограничения. Для фоновых уведомлений нужно нативное приложение.
✓ Сейчас работают только when app is active (in-app notifications)
